OVERVIEW

このアプリでできること

📱来場者はQRをかざすだけ

アプリのダウンロード不要・ログイン不要。ニックネームだけで参加できます。

🖥運営はブラウザだけで管理

QRコードの発行から特典管理まで、すべてノーコードで完結します。

🗂「プロジェクト」単位で運用

フェス・連続ライブなど複数イベントを1つのプロジェクトにまとめて管理できます。

🎁特典チケットを自動付与

スタンプが規定数に達すると引換券を自動発行。当日の引き換え対応もアプリ上で完結。

全体の流れ：来場者 → QRスキャン → スタンプ獲得 → 特典ゲット ／ 運営 → 管理画面 → QR発行 → 特典引き換え

アカウント作成とプロジェクト申請

👤 アカウント作成

/admin/signup　メールアドレスとパスワードを入力するだけ（確認メール不要）。

📋 プロジェクト申請

① メールアドレス指定

プロジェクト詳細画面から相手のメールアドレスを入力して追加。
相手が先に /admin/signup でアカウント作成済みである必要があります（招待メールは送られません）。

② 参加コード

プロジェクト詳細に表示される参加コードを共有 → 相手が /admin の「参加コードで参加」から入力。

ADMIN 3/6

イベント作成とQRコード発行

🎫 イベント作成

プロジェクト詳細 →「新規作成」。イベント名・開催日・会場名・アイコン画像（任意）・説明（任意）。作成後も編集可能。

🔳 QRコード発行

イベント一覧の「QR」ボタン → 「QRコードをダウンロード」でPNG保存 → 印刷して会場に掲示するだけ。

📊 確認できる情報

イベントごとの取得数をリアルタイム確認。取得者一覧（名前・性別・年齢・取得日時）はCSVダウンロード可能。

📍 マップピン設定（任意）

A

未獲得スポット：青い丸＋ラベル

✓

獲得済みスポット：テーマカラー＋チェック

  • イベント編集画面の「マップ上のピン位置」セクション
  • 会場マップ登録済みならマップをタップするだけで位置を自動設定
  • ラベル欄に A / B / C などを入力して保存
  • 来場者がピンをタップするとスポット詳細と獲得案内を表示
  • 取得済みスポットは自動でチェックマークに変化

ADMIN 4/6

動的QR ― 1枚のQRで時間帯切り替え

💡 こんな場面で使う

路上ライブなどで、同じスポットに複数のアーティストが時間交代で出演するとき。QRコードは1枚のまま、スキャンした時刻によって対応アーティストのスタンプが自動で押されます。

📲 スキャン時の動作

  • 時間帯内 → 対応アーティストのスタンプページへ自動リダイレクト
  • 時間外 → 「受付時間外です」と次回開始時刻を表示

⚙️ 設定手順

1
スロット管理を開く

プロジェクト詳細 →「スロット管理（動的QR）」

2
スロット名を作成

例：ステージA

3
タイムテーブルを設定

開始・終了時刻とイベントを選んで追加（日本時間）

4
QRをダウンロードして掲示

ADMIN 5/6

特典段階 ― 貯めたらもらえるを設定する

🎯 特典段階とは

「スタンプ◯個で〇〇プレゼント」を複数段階設定できる仕組み。

3個 → ステッカー 5個 → フォトカード 10個 → サイン会

🛠 設定方法

プロジェクト詳細 →「特典段階」セクション → 個数・特典名を入力 → 追加。

⚡ 自動付与の仕組み

来場者がスタンプを取得するたびに自動チェック。達成していれば即座に特典チケットを発行し、スタンプ帳の「チケット」タブ（引換券一覧）に表示されます。

📋 達成者の確認

プロジェクト詳細で取得者一覧（名前・段階・日時・引換状態）を確認できます。CSVダウンロードにも対応。

ADMIN 6/6

特典引き換え ― 当日スタッフの操作

🔄 引き換え手順

1
スタッフが引き換え画面を開く

管理画面ヘッダー「引き換え」または /admin/redeem（メンバーなら誰でも操作可）

2
来場者の引換券QRをスキャン

来場者はスタンプ帳「チケット」タブに引換券QRを表示

3
内容を確認して「引き換えする」

画面に来場者名と特典内容が表示される

4
確認画面で「確定（引き換える）」

2段階確認。確定すると使用済みに（取り消し不可）

🛡 二重引き換え防止

一度確定した引換券は再利用できません。同じQRを再度スキャンすると「引き換え済み」と表示されます。別スタッフとの処理の重複も防げます。

「確定（引き換える）」は押した後に取り消せません。来場者名と特典内容を必ず確認してからタップしてください。

NOTES 1/2

使用上の注意 ― 来場者データについて

🚫 シークレットモードはNG

来場者データはブラウザの「ローカルストレージ」に保存されます。シークレット（プライベート）モードで開くと別管理になり、スタンプ帳が空に見えたり、閉じると消えたりします。

来場者への案内：通常モード・同じブラウザで開いてください

🔑 復元コードの保存を案内する

機種変更やブラウザのデータクリアでデータが消えることがあります。ヘッダーのニックネーム →「ユーザー情報」に表示される復元コードで別端末から復元できます。

来場者への案内：復元コードはスクリーンショットで保存を

1️⃣ 同じイベントのスタンプは1回のみ

同じQRを何度読み取っても2回目以降は「取得済み」と表示され、スタンプは増えません（1ライブ1スタンプの仕様どおりの動作です）。

🚪 ログアウトは端末のデータを消すだけ

「ログアウト」はこの端末のローカル保存を消去するのみで、サーバー側のスタンプ・特典は残ります。復元コードがあれば同じスタンプ帳に戻れます。※サーバー側から完全削除する機能は現状ありません。

NOTES 2/2

使用上の注意 ― 運営操作について

① 承認前はイベントを作れない

承認タイミングに左右されるため、プロジェクト申請は早めに。

② 特典段階の個数変更は過去に影響しない

3個→5個に変えても付与済みはそのまま。ラベル変更は安全。段階を削除すると付与済み特典も消えます（要注意）。

③ 動的QRの時刻は日本時間（JST）

スケジュールの時刻入力は日本時間基準。入力どおりに切り替わります。

④ スケジュール重複時は早い方が優先

開始時刻が重複した場合は早い方を採用。重複しない設定を推奨。

⑤ 「確定（引き換える）」は取り消せない

使用済みに変更した後、元に戻す機能はありません。確定前に必ず確認を。

⑥ プロジェクト削除は元に戻せない

イベント・スタンプ・特典データがすべて削除されます。削除前にCSVでバックアップを。

⑦ インターネット接続が必要

スキャン・取得・引き換えはすべてサーバー通信が必要です。会場のWi-Fi / 4G / 5G環境を事前に確認してください。

FAQ

よくある質問・トラブル対応

スタンプが消えてしまった

シークレットモードや別ブラウザで開いた可能性があります。復元コードがあれば復元できます。

QRを読み取っても反応しない

① URLが正しいか（スロット型は受付時間外だとエラー表示）② インターネット接続 ③ カメラのアクセス許可、の順に確認してください。

特典チケットが表示されない

スタンプ帳の「チケット」タブが選択されているか、スタンプ数が段階の個数に達しているかを確認してください。

「引き換え済みです」と出た

すでに別のスタッフが引き換え処理を完了しています。二重引き換えを防ぐ正常な動作です。

スタッフを管理画面に追加したい

プロジェクト詳細から ① 登録済みメールアドレスの指定、または ② 参加コードの共有で追加できます（①は相手が事前にセルフ登録済みであることが必要）。

イベントのQRコードを紛失した

プロジェクト詳細 → イベント一覧の「QR」ボタンから再表示・再ダウンロードできます。QRコード自体は変わりません。

お困りの際は運営管理者までご連絡ください　｜　https://stamp-rally-kappa.vercel.app
